ニッチ用途 — レトロ / 組込み / アセンブリ

あなたの開発に直結する論点

結論：単独の本命はない。検証ゲートが本体です。

アセンブリ／レトロハード専用の比較ベンチマークは存在を確認できませんでした。どのツールも「アセンブリ／組込みで他社を圧倒」という検証済み証拠は見つかっていません。実務解は、モデル非依存ハーネス（Aider / OpenCode / Cline）＋最強推論モデルを小さい単位で使い、データシート／マニュアルを文脈に入れ（大文脈の Claude が有利な場面あり）、アセンブル→逆アセンブル比較、エミュレータ／HILテスト等の機械的検証を必須化することです。

🟢 楽観材料 — レガシー言語は急改善

OpenAI 自己申告、2026-10-20公開の低リソース言語評価 MultiLangBench：GPT-6 Astra 平均 87.4%（前世代26.8%）、COBOL 72.1%（10.9%→）、Fortran 83.5%、VB 89.4%、OCaml 85.8%。COBOL移行は GPT-6.1 Sol が低推論86.6%／高推論97.9%。「新規記述・移行」は Codex系が急改善と言えます。ただし Astra は高価格帯で Pro枠の消費も重い。
