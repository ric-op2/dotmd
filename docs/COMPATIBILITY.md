# 仕様と制限

対象：v0.60（2026-09-15）

## 仕様と制限

- FDS形式、片面、1人用。NTSCを前提としています。
- プレイ中のポーズ機能はありません。
- 6曲それぞれで、EASY／HARDとRANDOMのON／OFFが1つのハイスコアを共有します。
- 旧版のセーブデータとの互換性は保証していません。
- 譜面の生成・編集・取り込み機能は配布物に含みません。
- 説明書の印刷データはA4両面用です。

## 不具合の報告

配布元リポジトリのIssuesへ、タイトル右下のゲームの版、エミュレーター名とバージョン（実機なら機器構成）、曲名、難易度、RANDOM設定、発生した場面、再現手順を記載してください。
