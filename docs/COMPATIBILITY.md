# 動作確認と制限

対象：v0.60（2026-09-15）

## この版で確認した範囲

FCEUmm（WebAssembly版）で、以下を自動確認しています。

- 全6曲のEASY／HARD：完走、全取得、プレイ時間、CLEAR演出。
- タイトルの表示、待機中の明るさの揺らぎ、START後の点滅、STARTを押し続けた場合の動作。
- 取得エフェクトのGood／JUSTの差、同時1つの制限、MISSで発生しないこと、確認した場面でのスプライト数。
- ハイスコアの保存・非保存、リセット後の記録復元。
- キューブとコーナーのMISS時のゲージ減少、残量が少ないときの0への切り下げ、FAIL。
- 小さな暗いグレーのバージョン表示、リセット後のタイトル再表示。
- OBSIDIAN DRIVEの紫の配色、旋回中の配色維持。

自動操作によるコア単位の確認です。全曲確認はRANDOM OFFを対象としています。各エミュレーターのすべての版、アプリ側の設定、入力機器、音声遅延までを確認したものではありません。

以前の版ではNestopia・Mesenでも全曲と保存を確認しましたが、v0.60では再確認していません。

## 実機とFDSKEY

FDSKEYの読込みに必要な区切りとCRCを含めた物理使用量は66,097 / 66,560バイトです。容量の計算は通っていますが、実機とFDSKEYでのプレイ・保存は未確認です。

## 仕様と制限

- FDS形式、片面、1人用。NTSCを前提としています。
- プレイ中のポーズ機能はありません。
- 6曲それぞれで、EASY／HARDとRANDOMのON／OFFが1つのハイスコアを共有します。
- 旧版のセーブデータとの互換性は保証していません。
- 譜面の生成・編集・取り込み機能は配布物に含みません。
- 説明書の印刷データはA4両面用です。実際のプリンターでの試し刷りは未実施です。

## 不具合の報告

配布元リポジトリのIssuesへ、タイトル右下のゲームの版、エミュレーター名とバージョン（実機なら機器構成）、曲名、難易度、RANDOM設定、発生した場面、再現手順を記載してください。
