# タイミング調整（FDS版 v0.62）

曲選択画面で、SELECTを押したままSTARTを押してください。
見出しが「TIMING ADJUSTMENT」に切り替わり、曲名欄に「OFFSET」と調整値が表示されます。

| 操作 | 動作 |
|---|---|
| 左／右 | 1フレームずつ調整（−12〜12F） |
| B | 調整値を0に戻す |
| START | 設定を確定して保存 |

プラス側では判定の基準を遅らせ、マイナス側では早めます。0が標準です。
左右を押し続けても1回分だけ変わります。少しずつ変えながらプレイして合わせてください。

STARTで確定すると「SAVING」が表示されます。保存が終わると、元の曲・難易度の選択画面へ戻ります。
設定はディスクに保存され、次回起動時にも引き継がれます。
「SAVE ERROR START RETRY」が出た場合は、ディスクの状態や書込み設定を確認し、STARTで再試行してください。
保存中は終了・リセット・ディスクの取り外しをしないでください。

曲選択画面でSELECTだけを使う場合、難易度はボタンを離したときに切り替わります。
タイトル画面からはタイミング調整を行いません。

この補足はFDS版の操作です。ブラウザ版では画面下の「タイミング」を使ってください。
