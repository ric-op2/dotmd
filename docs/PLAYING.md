# 起動と保存

## はじめて遊ぶとき

1. Releasesの `DOTMD-v0.60.zip` をダウンロードし、フォルダーへ展開します。
2. FDS形式に対応したエミュレーターを用意します。必要なBIOSの設定は、使用するエミュレーターの説明に従ってください。BIOSは同梱していません。
3. 展開した `DOTMD-v0.60-6SONGS.fds` をエミュレーターで開きます。
4. コントローラー1の十字ボタン・A・B・START・SELECTを設定します。
5. タイトル画面でSTARTを押し、曲と難易度を選んで、もう一度STARTを押します。

本作はNTSCを前提としています。
エミュレーターの早送り・スロー再生を解除し、通常速度で遊んでください。

操作やルールは[取扱説明書](DOTMD-Booklet-88mm.pdf)をご覧ください。

## ハイスコアを保存する

ハイスコアを更新すると保存確認が表示されます。左右でYES／NOを選び、AまたはSTARTで決定してください。

- YES：新しい記録を保存します。
- NO：保存せず、前の記録を残します。

記録は曲ごとに共有され、EASY／HARD、RANDOMのON／OFFで分かれていません。
「SAVING...」の表示中は、終了・リセット・ディスクの取り外しをしないでください。

エミュレーターによって、記録をFDSファイルへ書き戻す場合と、別の保存ファイルへ記録する場合があります。保存先と終了時の扱いは、お使いのエミュレーターの設定を確認してください。

## 以前の版から更新するとき

古いゲームと保存データをバックアップし、新版を別フォルダーに展開してください。
旧版のセーブデータとの互換性は保証していません。新しい配布ファイルはハイスコア未記録の状態です。
古いステートセーブを新しいゲームへ読み込まないでください。

ダウンロード時のチェックサムは未プレイの配布ファイルに対する値です。ゲーム内保存でFDS自体が変更される環境では、プレイ後に値が変わる場合があります。

## 困ったとき

- **タイトルが出ない**：FDS対応環境とBIOS設定を確認してください。
- **STARTが反応しない**：一度ボタンを離してから押し直してください。
- **DISK READ ERROR**：ディスクの読込み状態を確認し、STARTで再試行してください。
- **記録が残らない**：YESを選んだか、保存先が書き込み可能か、終了時に保存が反映されたかを確認してください。


## 紙の説明書を作る

[A4両面印刷用PDF](DOTMD-Booklet-A4-Duplex.pdf)を、A4縦・両面長辺とじ・実際のサイズ100%で印刷します。1枚を3つの見開きに切り分け、重ねて折ると88mm角の冊子になります。
表紙と裏表紙を含めて12ページ、本文のページ番号は1〜10です。詳しくは[印刷と製本](PRINTING.txt)をご覧ください。
